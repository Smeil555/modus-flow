# Состояние проекта

## Реализовано

- Сервер FastAPI, SQLAlchemy и SQLite с включёнными внешними ключами, seed демонстрационных ролей и отделов.
- Вход с Argon2 и JWT в HttpOnly cookie, CSRF-проверка, ограничения попыток входа, серверные проверки ролей и доступа к обращениям.
- Создание обращений, анонимный токен с хранением хеша, локальная рекомендация, назначение отдела и исполнителя, базовые переходы статусов и история.
- Отдельный HTTP-симулятор 1С: поиск тестовых товаров и остатков, создание тестовой заявки с идемпотентностью, чтение статуса через API симулятора, запись интеграционных событий.
- Веб-интерфейс и базовые показатели из SQLite. Автоматические тесты основных прав и анонимности.

## Не завершено относительно мастер-промта

- React/TypeScript/Vite и требуемые frontend-библиотеки: текущий интерфейс на HTML/CSS/JS.
- Alembic-миграции, нормализованные таблицы всех сущностей, управление пользователями и отделами, категории и правила через интерфейс.
- Вложения, комментарии и уточнения, уведомления, сроки, расширенные фильтры и аналитика, похожие обращения, интеграция Bitrix24 и внешний AI.
- Все заданные переходы и действия по анонимному токену, полноценный мониторинг 1С, обновление статуса заявки из интерфейса, реальный адаптер 1С.
- Защита от перебора распределёнными средствами, комплексная проверка безопасности, frontend и полноценные сквозные тесты. CI настроен, но ещё не запускался на GitHub.
- GitHub CLI не установлен; удалённый репозиторий не создан и публикация не выполнялась. Создание приватного репозитория и push требуют отдельного подтверждения по мастер-промту.
