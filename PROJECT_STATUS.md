# Состояние проекта

## Работает

- FastAPI, SQLAlchemy, SQLite с внешними ключами, версиями схемы Alembic и импортом старой базы с резервной копией.
- React/TypeScript/Vite, адаптивный интерфейс, светлая и тёмная темы.
- Argon2, JWT в HttpOnly cookie, CSRF, отзыв сессии при выходе, серверные проверки ролей и принадлежности обращения. Администратор управляет пользователями, отделами и дополнительными ролями; пользователь переключает назначенный рабочий контекст.
- Создание обращений, рекомендация по управляемым правилам, назначение отдела и исполнителя, сроки, базовые переходы и история. Категории и правила доступны администратору.
- Анонимный токен хранится как хеш, автор не связан с обращением; просмотр, ответ на уточнение, повторное открытие и закрытие доступны по токену. Токен очищается при выходе из системы.
- Комментарии, внутренние уведомления, защищённые вложения. Для анонимных обращений принимаются только перекодированные изображения без исходного имени и метаданных. Отдельный обработчик формирует напоминания о сроках.
- Отдельный HTTP-симулятор 1С: поиск тестовых товаров и остатков, идемпотентное создание заявки, демонстрационное изменение и получение статуса, журнал запросов, монитор обмена. Есть заготовка клиента для согласованного HTTPS-сервиса реальной 1С.
- Аналитика из SQLite, график по отделам, сроки реакции и решения, отметка реализованных предложений и локальный поиск похожих доступных пользователю обращений. Фильтры включают статус, категорию, отдел, приоритет, даты и наличие обмена с 1С. Презентация: `deliverables/MODUS_FLOW_1C.pptx`.

## Что остаётся до полного соответствия мастер-промту

- Для анонимных вложений запрещены PDF и текстовые документы: их безопасное обезличивание не реализовано. Содержимое изображений может само раскрывать личность.
- Расширенная аналитика смысловой повторяемости, дополнительные элементы управления пользователями и сквозные проверки всех комбинаций переходов остаются незавершёнными.
- Реальная интеграция Bitrix24 (сейчас имеется только интерфейс), внешняя AI-классификация и согласованное подключение настоящей 1С/OData. Реальный клиент не тестировался с 1С.
- Антивирусная проверка вложений, независимый аудит безопасности, production-инфраструктура и дополнительные интеграционные и браузерные тесты. Общий ограничитель запросов работает через общую базу, но не проверялся под промышленной нагрузкой. CI настроен, но не запускался на GitHub.
- Приватный репозиторий создан: https://github.com/Smeil555/modus-flow. Локальная ветка `main` связана с `origin/main`; GitHub CLI не установлен.

## Последняя проверка

Проверены чистая установка и миграция заполненной базы, целостность SQLite, серверные и React-тесты. В браузере пройдены основной сценарий с анонимным обращением и симулятором 1С, редактирование анонимного обращения и переключение назначенной роли. Проверки не заменяют независимый аудит безопасности или испытание с реальной 1С. Для промышленного применения проект ещё не готов.
