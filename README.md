# MODUS FLOW

Рабочий прототип системы обратной связи: FastAPI, SQLAlchemy, SQLite и отдельный HTTP-симулятор 1С:УТ. Симулятор не является 1С. Состав реализованного и оставшиеся задачи перечислены в [PROJECT_STATUS.md](PROJECT_STATUS.md). Используйте только синтетические данные: проект ещё не готов к промышленной эксплуатации.

## Запуск в Windows PowerShell

Из корня проекта, Python 3.11+:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:SESSION_SECRET = 'замените-на-случайное-значение-не-короче-32-символов'
$env:DEMO_PASSWORD = 'задайте-уникальный-демо-пароль'
python -m scripts.seed
python -m uvicorn mock_1c.main:app --port 8001
```

Во втором окне PowerShell активируйте окружение, повторите установку `SESSION_SECRET` и запустите `python -m uvicorn backend.main:app --port 8000`. Откройте http://localhost:8000. Логины: `employee`, `admin`, `manager`, `executor`; пароль задаётся `DEMO_PASSWORD` при первом запуске seed. Повторный seed не меняет существующие пароли. API: http://localhost:8000/docs, симулятор: http://localhost:8001/docs.

Локально зависимости могут быть установлены в `.vendor`: вместо активации venv задайте `$env:PYTHONPATH = '.vendor;.'`. В защищённой среде нужны HTTPS, `COOKIE_SECURE=1`, отдельные секреты, внешний ограничитель запросов и полноценный аудит безопасности.

## Демонстрация

1. Войдите как employee и отправьте анонимное обращение «На складе не работает сканер штрихкодов». Сохраните показанный один раз токен.
2. Войдите как admin, откройте обращение и назначьте предложенный технический отдел.
3. Войдите как manager и назначьте executor. Исполнитель открывает обращение, запрашивает товары, создаёт тестовую заявку и отмечает решение.
4. Admin видит историю и показатели. Employee может открыть анонимное обращение через токен.

SQLite хранит хеш токена, но не автора анонимного обращения. Не вводите имя и идентифицирующие детали в тексте: система не может автоматически гарантировать их отсутствие. Сетевые и серверные журналы могут содержать технические метаданные.

## Проверка

`python -m pytest -q` при установленном `PYTHONPATH`. Базу `modus.db` можно скопировать средствами SQLite backup API при остановленном сервере; не добавляйте её в Git. `mock1c.db` содержит только тестовые заявки симулятора.

## 1С:УТ

Интеграция демонстрационная: отдельный сервис возвращает товары и остатки, а также создаёт тестовые заявки с idempotency key. Для реальной 1С понадобятся согласованные интерфейсы OData или опубликованный HTTP-сервис, права сервисной учётной записи, схема данных, TLS и проверка бизнес-правил. Реальный адаптер ещё не реализован. См. [описание интеграции](docs/1c.md).
