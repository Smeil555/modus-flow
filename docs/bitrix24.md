# Заготовка Битрикс24

`backend.bitrix.BitrixClient` задаёт контракт создания задачи и получения её состояния. В проекте нет работающего подключения к Битрикс24: вызов фабрики сообщает, что интеграция не настроена. Перед реализацией нужны согласование владельца портала, способа авторизации, минимальных прав, сопоставления сотрудников и статусов, идемпотентности и правил передачи конфиденциальных данных. Анонимные тексты нельзя передавать во внешнюю систему без отдельного разрешения и мер защиты.
